Ludo Land Audio Resources (res/raw)

Drop your custom audio files into this res/raw directory with the following exact filenames:

1. dice_roll.mp3 - Audio effect played when rolling the 3D dice.
2. token_move.mp3 - Short click/pop sound played as tokens hop along the board.
3. capture.mp3 - Impact sound effect played when capturing an opponent token.
4. home_reach.mp3 - Chime sound played when a token reaches the home goal.
5. win.mp3 - Fanfare / celebration cheer played when a player wins the game.
6. button_click.mp3 - Tactile tap sound played on ClayButton clicks.

Note: The included SoundManager uses built-in synthesizers (ToneGenerator) as an automatic fallback if these audio files are absent.
